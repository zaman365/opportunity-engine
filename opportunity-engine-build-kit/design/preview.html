This exploration uses a case index, an artifact stage, numbered provenance, and a review seam. There is no decorative KPI grid because evidence—not a generic overview—is the primary working material.

What the designer should challenge

Typography, composition, density, navigation expression and how evidence links to a judgment. Explore materially different layouts using the same task, not three versions of the same palette.

What must remain true

Evidence, interpretation, uncertainty and permission remain distinct. Every key action works with keyboard and narrow screens. Real system state replaces fiction in the production build.
