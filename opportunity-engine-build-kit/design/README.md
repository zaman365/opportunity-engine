# Designer handoff

Read DESIGN_BRIEF.md first. It distinguishes fixed product responsibilities from the creative decisions you own. UI_SPEC.md provides behavior and states; DESIGN_SYSTEM.md gives provisional token logic; COMPONENTS.md and COPY.md make the handoff implementable; QA.md defines critique and acceptance.

Open preview.html directly. It is self-contained, offline, synthetic and interactive. It is **one design exploration, not the required final template**. Improve or replace its expression through the concept process, retaining the evidence/permission/task truth.

Use prompts/01_DESIGN_DIRECTOR.md when briefing a design-capable coding or design tool. No font binaries, real merchant assets or proprietary UI screenshots are included.
