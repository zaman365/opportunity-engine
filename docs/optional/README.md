# Optional and deferred scope

Work that is **not** part of the Brand Consistency Scanner as it is being built. Each file
records what the idea was, what it would cost, and what would have to be true before it became
worth doing.

Nothing here is implemented. No code in this repository connects to any of it, and none of it
is a dependency of any milestone in [`docs/roadmap`](../roadmap/).

| File                                                     | What it defers                                     |
| -------------------------------------------------------- | -------------------------------------------------- |
| [SHOPIFY_CONNECTOR.md](SHOPIFY_CONNECTOR.md)             | Shopify OAuth, product sync, store tokens          |
| [TREVV_HANDOFF.md](TREVV_HANDOFF.md)                     | Passing approved work to TREVV                     |
| [FUTURE_VENTURE_ADAPTERS.md](FUTURE_VENTURE_ADAPTERS.md) | LokalFix, MikroIT and other vertical adapters      |
| [AGENCY_SAAS_EXPANSION.md](AGENCY_SAAS_EXPANSION.md)     | Agency SaaS, marketplace, data licensing, crawling |

## Why these are written down rather than deleted

Two reasons. A deferred idea that is not recorded gets re-proposed every few months by
whoever last read the handoff. And each of these has a real condition attached — the point is
not that they are bad, it is that they are not this product, yet.
